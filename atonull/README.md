# atonull

**Attendee:** [@atonull](https://github.com/atonull)

**Project:** Drift, a bedtime story generator designed in Claude Design. Pick a setting, mood and sleep timer, and get a calm story player, plus a "My stories" library with filters, search and favorites. The home page is `index.html` and the library is `library.html`.

**Status:** Front-end prototype. Story generation and narration are placeholders, and the six library stories are sample data (edit the `stories` list in `library.js`).

**Run locally:** from this folder, run `python3 -m http.server 8000` and open http://localhost:8000.
